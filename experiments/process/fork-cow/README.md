# OS-002 fork-address-space

## 实验目的

fork 前变量为 1。子进程写成 2 后，父进程中的变量仍为 1。子进程的 ru_minflt 记入度量，不作为通过条件。

## 程序实际检查的内容

子进程把自己的 value 改为 2 后正常退出。父进程的 value 仍为 1。

## 不由本实验断言的内容

ru_minflt 只是度量。它为 0 或不为 0 都不单独证明物理页是否复制。
