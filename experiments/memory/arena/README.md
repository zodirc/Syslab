# MEM-001 arena-lifo

## 实验目的

释放最后一次 32 字节分配后，下一次相同请求返回同一地址。再次释放该地址抛出 syslab::Error。

## 程序实际检查的内容

释放最后一次 32 字节分配后，下一次相同请求返回同一地址。随后的第二次释放抛出 syslab::Error。

## 不由本实验断言的内容

本节释放的是第二次分配。通过条件是下一次 32 字节请求返回同一地址，以及第二次 deallocate 抛出 syslab::Error。

反汇编、系统调用跟踪、ELF 元数据和耗时进入本次运行的观察记录。工具不存在或本次没有采样时，记录的状态是 unavailable 或 unsupported，程序不补造这些数据。
