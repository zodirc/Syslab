# MEM-009 shared-weak

## 实验目的

检查 shared/weak 在没有循环强引用时销毁对象，并检查 unique 所有权移动。

## 程序实际检查的内容

两个节点离开作用域后析构次数为 2，weak 过期。移动后的 UniquePtr 持有值 4，原指针为空。

## 不由本实验断言的内容

若两边都保存 SharedPtr，对象会留下来。本实验故意不构造那个循环，并在说明里指出这一点。
