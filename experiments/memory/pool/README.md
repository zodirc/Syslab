# MEM-002 fixed-pool

## 实验目的

4 个 32 字节块分配成功。第 5 次 32 字节请求和 64 字节请求都返回空指针。归还一块后，32 字节请求返回非空。

## 程序实际检查的内容

四次 32 字节请求返回非空。第 5 次 32 字节请求和 64 字节请求返回空指针。deallocate 一块之后，32 字节请求返回非空。
