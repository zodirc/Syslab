# CTR-006 net-namespace

## 实验目的

确认新网络命名空间可以索引 `lo`，不能索引进入该命名空间之前选中的另一块网卡。原命名空间仍能索引那块网卡。

## 程序实际检查的内容

进入之前用 `SIOCGIFCONF` 选择第一块名字不是 `lo` 的已配置接口。`fork` 发生在 `unshare(CLONE_NEWNET)` 之前。新命名空间里 `lo` 的 `SIOCGIFINDEX` 大于 0，那块网卡的调用失败。原命名空间里同一名字的索引大于 0。没有 `lo` 以外的已配置接口，或命名空间不能建立时，结果为不支持。

## 不由本实验断言的内容

本实验不读取 `/sys/class/net`。该目录可能仍是原来的 sysfs 挂载。本实验也不配置地址或路由。
