# SRV-004 read-deadline

## 实验目的

一条连接在 400 毫秒内没有收齐帧并被关闭。另一条连接收到 OK。

## 程序实际检查的内容

帧格式与 `SRV-002` 相同：4 字节大端长度和 4 字节载荷。一个连接建立后不再发送。另一个连接发送长度 4 和载荷 `FAST`。未收齐的连接计一次超时并关闭。收齐的连接得到两个字节 `OK`。运行器的 `timeout_ms` 是 20000，长于这里的 400 毫秒。

## 不由本实验断言的内容

一条连接在 400 毫秒内没有收齐帧并被关闭。另一条连接收到 OK。
