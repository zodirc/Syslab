# SRV-003 connection-tids

## 实验目的

确认两个已接受的连接分别由两个线程读取，并且两个 `tid` 互不相等。

## 程序实际检查的内容

两个客户端分别发送 `A` 和 `B`。每个已接受的连接在自己的线程里读取一个字节并记录 `syscall(SYS_gettid)`。两个 `tid` 都大于 0 且互不相等，`A` 和 `B` 都被读到。

## 不由本实验断言的内容

本实验不描述 `task_struct` 的布局，也不把 `tid` 解释成容器里的 pid。线程标识的核对方式与 `OS-003` 相同。

反汇编、系统调用跟踪、ELF 元数据和耗时进入本次运行的观察记录。工具不存在或本次没有采样时，记录的状态是 unavailable 或 unsupported，程序不补造这些数据。
