# SRV-002 length-prefix

## 实验目的

确认 4 字节大端长度和载荷没有一起到达时，不产生请求。两者收齐后只产生一次请求。

## 程序实际检查的内容

帧的长度字段为 4，载荷为 `ping`。只写入长度的前两个字节时，请求数为 0。长度到齐但载荷只到一个字节时，请求数仍为 0。其余字节到达后，请求数为 1，载荷为 `ping`。

## 不由本实验断言的内容

本实验使用一对已连接的字节流套接字。它不解析长度字段以外的协议，也不检查多个并发连接。

反汇编、系统调用跟踪、ELF 元数据和耗时进入本次运行的观察记录。工具不存在或本次没有采样时，记录的状态是 unavailable 或 unsupported，程序不补造这些数据。
