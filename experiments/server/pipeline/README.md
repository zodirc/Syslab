# SRV-005 pipelined-frames

## 实验目的

一次读入产生两帧，顺序是 AAAA、BBBB。尾部两个字节不构成第三帧。

## 程序实际检查的内容

字节流是长度 4 的 `AAAA`、长度 4 的 `BBBB`，以及随后的两个 0 字节。读端收齐后得到 2 次请求，载荷顺序是 `AAAA`、`BBBB`，剩余 2 字节。

## 不由本实验断言的内容

一次读入产生两帧，顺序是 AAAA、BBBB。尾部两个字节不构成第三帧。
