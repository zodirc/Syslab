# SRV-006 bounded-queue

## 实验目的

两个不同标记入队并得到 OKAY。第三个连接得到 BUSY。

## 程序实际检查的内容

三条连接分别发送 `A`、`B`、`C`。队列少于 2 项时回答 `OKAY` 并保存标记。已经有 2 项时回答 `BUSY`。入队数为 2，两个标记不同且都属于 `A`、`B`、`C`。客户端收到 2 次 `OKAY` 和 1 次 `BUSY`。

## 不由本实验断言的内容

两个不同标记入队并得到 OKAY。第三个连接得到 BUSY。

反汇编、系统调用跟踪、ELF 元数据和耗时进入本次运行的观察记录。工具不存在或本次没有采样时，记录的状态是 unavailable 或 unsupported，程序不补造这些数据。
