# AT-013 epoch-reclamation

## 实验目的

pin 期间退役一个对象，删除计数为 0。unpin 后再退役两个对象，删除计数为 2。

## 程序实际检查的内容

pin 期间退役一个对象后删除计数为 0。unpin 后再退役两个对象，删除计数为 2。

## 不由本实验断言的内容

三个对象里有一个在最后一次 retire 返回时仍留在延迟列表中。本节只 pin 一个 EpochDomain。

反汇编、系统调用跟踪、ELF 元数据和耗时进入本次运行的观察记录。工具不存在或本次没有采样时，记录的状态是 unavailable 或 unsupported，程序不补造这些数据。
