# CPU-003 stack-frame

## 实验目的

确认被取地址的局部对象在 Debug 和 Release 两种构建中仍然可读，并把栈帧差异留在反汇编里比较。

## 程序实际检查的内容

volatile int 的值仍是 7，它的地址非空。

## 不由本实验断言的内容

帧指针是否保留、栈槽是否被合并，取决于编译器和优化级别，不是 C++ 标准规定的固定布局。比较两个变体的反汇编时要同时看 build.json。
