# SYNC-003 mcs-lock

## 实验目的

同一节点在 unlock 返回后再次加锁。四个线程各递增 1000 次，计数为 4000。

## 程序实际检查的内容

同一节点加锁、解锁后再加锁、解锁。四个线程用 McsGuard 各递增 1000 次，计数为 4000。

## 不由本实验断言的内容

本节不构造 unlock 返回前销毁节点的用例。一次未崩溃不能代替那个用例。锁公平、不可重入。
