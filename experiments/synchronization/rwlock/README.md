# SYNC-005 rwlock

## 实验目的

核对已排队的写者是否先于后到的读者进入，并用两个写者检查写锁互斥。

## 程序实际检查的内容

主线程持有共享锁时，写者先排队，后到的读者也排队。主线程放开共享锁后，写者先进入。两个写者各递增 100 次，计数为 200，写锁没有重叠。

## 不由本实验断言的内容

这是这个实现的写优先。POSIX 读写锁还有其他合法策略。锁不可重入。没有线程持有或等待时才能销毁。
