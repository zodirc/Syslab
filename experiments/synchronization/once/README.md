# SYNC-010 mutex-slow-path-and-once

## 实验目的

在锁已被持有时让另一个线程进入 Mutex 慢路径，并检查 OnceFlag 只执行一次。

## 程序实际检查的内容

竞争线程启动后，slow_path_count 在解锁前大于 0。八个线程的初始化函数只进入一次。

## 不由本实验断言的内容

慢路径计数不是内核等待的证明。OnceFlag 的函数若抛出异常，状态回到未完成，本实验的函数不抛出。
