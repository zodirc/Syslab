# STO-006 page-checksum

## 实验目的

确认页校验和相符时返回 8 字节载荷。页内一个字节改变且校验和未更新时，不返回载荷。

## 程序实际检查的内容

校验和从 0 开始，对每个字节计算 `checksum = checksum * 131 + byte`。有效页的载荷是 `RECORD01`。把第一个字节异或 `0xFF` 并保留旧校验和之后，读取函数返回失败，调用方缓冲区的首字节仍是 `0x5A`。`fsync` 失败时结果为不支持。

## 不由本实验断言的内容

本实验不恢复被撕开的页，也不解释块设备的扇区原子性。

反汇编、系统调用跟踪、ELF 元数据和耗时进入本次运行的观察记录。工具不存在或本次没有采样时，记录的状态是 unavailable 或 unsupported，程序不补造这些数据。
