# STO-002 page-read

## 实验目的

确认页号乘以页长得到的文件区间可以独立读写。写入页号 1 之后，页号 0 的字节保持原值。

## 程序实际检查的内容

页长来自 `sysconf(_SC_PAGESIZE)`。页号 0 写入 `0xA1`，页号 1 写入 `0xB2`。按偏移 `1 * page_size` 读回的整页等于 `0xB2`，偏移 0 的整页仍等于 `0xA1`。

## 不由本实验断言的内容

本实验不检查页缓存、掉电之后的持久性，也不解释数据库如何组织多个页。环境快照里的 `page_size` 由运行器另行记录。

反汇编、系统调用跟踪、ELF 元数据和耗时进入本次运行的观察记录。工具不存在或本次没有采样时，记录的状态是 unavailable 或 unsupported，程序不补造这些数据。
