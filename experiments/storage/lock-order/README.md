# STO-004 lock-order

## 实验目的

确认两把互斥量按相同顺序获取时两次更新都写入，按相反顺序获取时在超时后放弃更新。

## 程序实际检查的内容

两个线程分别先持有锁 0 和锁 1，再对另一把锁调用 `pthread_mutex_timedlock`，期限 300 毫秒。两次调用都返回 `ETIMEDOUT`，更新计数保持 0。随后两个线程都按锁 0、锁 1 的顺序获取，更新计数变为 2。

## 不由本实验断言的内容

本实验不测量等待时间的分布，也不把超时解释成某一种硬件内存序。互斥量本身的三态见 `SYNC-004`。

反汇编、系统调用跟踪、ELF 元数据和耗时进入本次运行的观察记录。工具不存在或本次没有采样时，记录的状态是 unavailable 或 unsupported，程序不补造这些数据。
