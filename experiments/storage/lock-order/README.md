# STO-004 lock-order

## 实验目的

两边都持有第一把锁时，对另一把锁的 trylock 返回 EBUSY，更新数是 0。相同顺序完成后更新数是 2。

## 程序实际检查的内容

两个线程分别先持有锁 0 和锁 1，再对另一把锁调用 `pthread_mutex_timedlock`，期限 300 毫秒。两次调用都返回 `ETIMEDOUT`，更新计数保持 0。随后两个线程都按锁 0、锁 1 的顺序获取，更新计数变为 2。
