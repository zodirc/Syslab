# STO-005 wal-replay

## 实验目的

完整日志重放得到 ABCDEFGH。截断到第一条已提交记录后再重放，页保持 ABCD....。

## 程序实际检查的内容

页的初始内容是 8 个 `.`，`applied_lsn` 为 0。第一条记录 `lsn=1` 在偏移 0 写入 `ABCD`，追加并 `fsync` 之后应用到页。第二条记录 `lsn=2` 在偏移 4 写入 `EFGH`，只追加到日志。此时重放得到 `ABCDEFGH`，`applied_lsn` 为 2。把页恢复到第一条记录提交后的镜像，并把日志截断到该记录末尾，再次重放得到 `ABCD....`，`applied_lsn` 为 1。`fsync` 失败时结果为不支持。

## 不由本实验断言的内容

完整日志重放得到 ABCDEFGH。截断到第一条已提交记录后再重放，页保持 ABCD....。

反汇编、系统调用跟踪、ELF 元数据和耗时进入本次运行的观察记录。工具不存在或本次没有采样时，记录的状态是 unavailable 或 unsupported，程序不补造这些数据。
