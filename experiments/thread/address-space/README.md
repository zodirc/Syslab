# OS-004 thread-vs-fork

## 实验目的

新线程写入 1，join 之后原线程读到 1。子进程写入 5，父进程中的值仍为 1。

## 程序实际检查的内容

线程把 shared 写成 1，join 之后父线程读到 1。子进程修改 isolated 后，父进程仍读到 1。

## 不由本实验断言的内容

fork 之后虚拟地址数值常常相同，这不表示物理页相同。本实验不断言地址数值或 COW。
