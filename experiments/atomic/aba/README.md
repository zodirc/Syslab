# AT-007 tagged-aba

## 实验目的

用带版本号的字模拟 ABA：旧版本的比较交换失败。

## 程序实际检查的内容

第一次 CAS 把 tag 从 0 改为 1。随后用 tag 仍为 0 的期望值做 CAS 必须失败，指针保持为 1。

## 不由本实验断言的内容

这不是无锁栈里真实发生的 ABA。它只演示版本号使复用后的旧期望值失效。Slot 必须是可平凡复制的，本结构满足这一点。
