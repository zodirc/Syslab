# 锁

TAS、ticket 和 futex mutex 用互斥计数检查。MCS 的节点放在 `McsGuard` 内，必须活到 `unlock` 返回。读写锁是写优先的教学实现，不是某一种 POSIX 策略的唯一形式。递归互斥量只允许拥有者重入。

Mutex 状态 0 是未锁，1 是已锁且没有公布等待者，2 是已锁且有等待者。`slow_path_count` 在快路径比较交换失败时增加。它不证明 futex 已经睡眠。SYNC-010 在持锁期间等这个计数变为非零。

条件变量用序列号关闭丢失唤醒：通知若发生在等待之前，`FUTEX_WAIT` 会因为字不匹配而返回。信号量在计数为 0 时等待。屏障用代数发布，最后到达的线程增加代数。`OnceFlag` 在初始化函数抛出时回到未完成，让其他调用者重试。
